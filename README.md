# Flipkart Sales Data Analysis

## Project Overview
Analyzed Flipkart sales data using Excel to clean messy data,
create Pivot Tables and generate sales reports.

## Tools Used
- Microsoft Excel
- Advanced Excel
- Pivot Tables
- Excel Charts
- Data Cleaning

## Work Performed
- Cleaned duplicate and missing data
- Formatted raw sales data
- Created Pivot Tables
- Analyzed quarter-wise sales
- Created charts for sales analysis
- Prepared an interactive sales report

## Key Insights
- Identified quarter-wise sales performance
- Compared product/category sales
- Analyzed overall sales trends
